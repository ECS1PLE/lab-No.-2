# Поиск статей в Википедии

Графический интерфейс на Tkinter

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

Нужны Python 3.10 или новее, графический рабочий стол и доступ к интернету.
Tkinter входит в стандартную библиотеку Python; в Ubuntu/Debian при его
отсутствии установите пакет `python3-tk` (`sudo apt install python3-tk`).
